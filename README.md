# Local CI dry-run for GitHub Actions

> **Status: scaffold only.** The idea below is the plan, not what the code does yet — the package currently contains no implementation. Watch the repo if you want to know when it does something.


Validates and runs a workflow's shell steps in a Docker container locally, with a plain-language report of which features (matrix, services, secrets) are unsupported. Aimed at people who don't want to push repeated 'fix ci' commits.
